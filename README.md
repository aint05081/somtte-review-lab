# SOMTTE Review Lab

올리브영 실제 토너패드 리뷰 4,380개에서 **소비자 문체 분포**를 참고하고,
솜떼 센텔라 카밍 / 솔라눔 올클리어 실제 리뷰에서 **제품별 소구**를 분리해 참고하는 내부용 가상 리뷰 샘플 생성기입니다.

## 사용법
1. 제품 선택: 센텔라 카밍 / 솔라눔 올클리어
2. 길이 선택: 자동 / 짧게 / 보통 / 길게
3. 결과 수 선택: 1 / 3 / 5 / 10 / 20개
4. 리뷰 만들기

별도의 실제 사용 경험 입력은 필요하지 않습니다.

## 데이터 역할
- `data/oliveyoung_mediheal.json`: 올리브영 문체 참고
- `data/oliveyoung_dermatory.json`: 올리브영 문체 참고
- `data/somtte_centella.json`: 센텔라 제품 소구 참고
- `data/somtte_solanum_allclear.json`: 솔라눔 올클리어 제품 소구 참고

## 실행
```bash
npm install
cp .env.example .env.local
# .env.local에 OPENAI_API_KEY 입력
npm run dev
```

브라우저: http://localhost:3000

## 주의
생성 결과는 실제 구매자의 사실을 재현하는 것이 아니라 데이터에서 확인된 제품 소구를 바탕으로 만든 **가상 리뷰 샘플**입니다.

## v4 변경사항
- 올리브영 원본 4,380개 / 완전 동일 본문 중복 제거 후 4,290개 분석 프로필 전체를 생성 프롬프트에 고정했습니다.
- 길이 분포(35.0% / 34.5% / 30.5%), 문장 수 감각, 첫 문장 유형, 종결어미, 구어체/인터넷 표현, ㅋㅋ·ㅎㅎ·ㅠㅠ·이모지·문장부호 빈도, 피부 타입/사용 상황 언급 비율, 8개 리뷰 스타일군, 별점별 온도, 자연스러운 비정돈성까지 모두 고려합니다.
- `자동` 길이에서 요청한 결과 수에 맞춰 리뷰별 길이/스타일 설계표를 먼저 만든 뒤 모델에 전달합니다.
- 입력값이 있는 경우 입력 사실 보존 규칙이 우선되며, 입력에 없는 재구매/피부 타입/사용 기간/효과를 사실처럼 추가하지 않습니다.
